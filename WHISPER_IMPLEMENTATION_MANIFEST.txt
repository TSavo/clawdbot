KEY FEATURES
================================================================================

DUAL DEPLOYMENT MODES
───────────────────

Docker Mode:
  - Containerized Whisper API service
  - Up to 4 concurrent transcription sessions
  - GPU support (NVIDIA CUDA with --gpus all)
  - Resource limits (CPU, memory configuration)
  - Health checks with periodic monitoring
  - Container logging and stats retrieval

System Mode:
  - Local Python package (pip install openai-whisper)
  - Single concurrent transcription session
  - CPU/CUDA/MPS device detection
  - Automatic model downloading and caching
  - Subprocess-based transcription
  - FFmpeg optional for format conversion

AUDIO PROCESSING
────────────────
  - Format normalization: PCM_16, 16kHz (universal)
  - Input formats: MP3, AAC, Opus, OGG Vorbis, WAV
  - Channel support: Mono and stereo
  - Stream-based processing with partial results
  - Configurable audio timeout

MODEL MANAGEMENT
────────────────
  - Model sizes: tiny, small, base, medium, large
  - Multilingual: 99+ language support
  - Automatic caching with configurable directory
  - Model preloading on initialization
  - Language auto-detection or manual specification

ERROR HANDLING
──────────────
  - Provider-specific error codes
  - VoiceProviderError wrapper class
  - Automatic health checking
  - Graceful timeout handling
  - Fallback provider chain support

RESOURCE MANAGEMENT
────────────────────
  - Health check intervals (non-blocking)
  - Process cleanup on shutdown
  - Container resource limits
  - Process timeout protection
  - Memory-efficient streaming

CONFIGURATION
──────────────
  - Environment variable driven
  - YAML provider configuration
  - Deployment mode auto-detection
  - Fallback mechanism (Docker → System)
  - Per-provider initialization

CONFIGURATION REFERENCE
================================================================================

ENVIRONMENT VARIABLES
────────────────────

Global:
  WHISPER_DEPLOYMENT=docker|system
    Default: auto-detect

Docker Mode:
  WHISPER_DOCKER_PORT=8000
  WHISPER_DOCKER_IMAGE=openai/whisper:latest

System Mode:
  WHISPER_PYTHON_PATH=/usr/bin/python3
  WHISPER_CACHE_PATH=~/.cache/whisper

YAML CONFIGURATION
──────────────────

providers:
  - id: whisper-stt
    enabled: true
    priority: 1
    stt:
      type: whisper
      modelSize: base           # tiny, small, base, medium, large
      language: en              # optional

INSTALLATION
─────────────

System Mode:
  pip install openai-whisper torch
  pip install ffmpeg-python   # optional

Docker Mode:
  docker >= 20.0
  OR manually: docker pull openai/whisper:latest

================================================================================
API REFERENCE
================================================================================

WhisperExecutor Interface
─────────────────────────

Methods:
  initialize(): Promise<void>
    Start the provider and download models if needed

  shutdown(): Promise<void>
    Stop the provider and clean up resources

  transcribe(audio: AudioBuffer, options?): Promise<TranscriptionResult>
    Transcribe a single audio buffer

  transcribeStream(stream: ReadableStream<AudioBuffer>): AsyncIterable<TranscriptionChunk>
    Transcribe audio stream with partial results

  getCapabilities(): ProviderCapabilities
    Get provider capabilities and supported formats

  isHealthy(): Promise<boolean>
    Check provider health status

  getDeploymentMode(): 'docker' | 'system'
    Get current deployment mode

Plugin Service Interface
────────────────────────

Methods:
  initialize(providerId, config): Promise<void>
    Initialize the provider with configuration

  detectDeploymentMode(): Promise<DeploymentDetection>
    Detect available deployment modes

  getStatus(): WhisperPluginServiceStatus
    Get current service status

  getExecutor(): WhisperExecutor | undefined
    Get the executor instance

  checkHealth(): Promise<boolean>
    Verify provider health

  restart(providerId, config): Promise<void>
    Restart the provider

  shutdown(): Promise<void>
    Shutdown the service

  getInfo(): Record<string, unknown>
    Get comprehensive service information

USAGE EXAMPLES
================================================================================

Basic Transcription:
  const executor = new WhisperExecutor('whisper-stt', { type: 'whisper', modelSize: 'base' });
  await executor.initialize();
  const result = await executor.transcribe(audioBuffer);
  console.log(result.text);

Registry Integration:
  const registry = new VoiceProviderRegistry();
  await registry.loadProviders(config);
  const executor = await registry.getTranscriber('whisper-stt');

Plugin Service:
  const service = getWhisperPluginService();
  await service.initialize('whisper-stt', { type: 'whisper' });
  const result = await service.getExecutor()?.transcribe(audioBuffer);

See QUICK_START.md and whisper.test.ts for more examples.
